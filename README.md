# 天赋财富测评系统

一个专业的天赋与商业能力测评网站，提供两种测评报告：

## 功能特点

### 1. 天赋创富测评
- **天赋力评估**：包含自我认知、自我接纳、自我笃定、天赋运用、天赋转化五个维度
- **创富力评估**：涵盖产品设计、营销推广、焦虑运营、成交转化、行动力、抗压力
- **天赋类型识别**：展示个人天赋类型标签
- **兴趣领域分析**：雷达图展示心灵成长、秩序概念、现实体验、秩序构建
- **交互方式分析**：评估一对一、社群、内容三种交互方式的适配度

### 2. 1V1商业测评
- **存在感（A）**：形象调商、高端仪态、不俗装扮、人格魅力、深度整合
- **引力场（B）**：流量合伙、主题演绎、起盘教授
- **说服力（C）**：价值塑造、需求心理、差异体验、产品包装、决策促进
- **价值力（D）**：结果承诺、快速解决、分段实践、资源合并、价值呈现
- **兑现力（E）**：触发场景、高质到付、口碑见证、客户运营、数据留存
- **续航力（F）**：社群、中端、平台、技能、低端
- **杠杆力（G）**：超高客单、高客单价、普通客单、引流低价
- **合力（H）**：决策力、竞争力、协作力、执行力

## 技术栈

- **前端框架**：纯HTML5 + CSS3 + JavaScript
- **图表库**：Chart.js 4.4.0
- **设计风格**：现代化、响应式设计
- **浏览器兼容**：支持所有现代浏览器

## 使用方法

1. 直接在浏览器中打开 `index.html` 即可访问网站首页
2. 点击相应按钮查看不同的测评报告示例
3. 所有页面均为静态页面，无需后端服务器

## 移动端测试

### 方法1：浏览器开发者工具
1. 打开Chrome开发者工具 (F12)
2. 点击设备工具栏图标 (Ctrl+Shift+M)
3. 选择不同设备进行测试

### 方法2：真实设备测试
1. 启动本地服务器：`python -m http.server 8080`
2. 在手机浏览器中访问：`http://[你的电脑IP]:8080`

详细的移动端优化说明请查看 `MOBILE_OPTIMIZATION.md`
